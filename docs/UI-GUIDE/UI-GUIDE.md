# UI Guide — Tab Overview

The Flexible GraphRAG UI provides a 5-tab interface for document processing and querying.
Available as React, Angular, and Vue frontends — all with the same capabilities — in the browser
or in the [Desktop App](../GETTING-STARTED/DESKTOP-APP.md), which adds local files and folders.

| Tab | Purpose |
|---|---|
| **[Sources](UI-TAB-SOURCES.md)** | Configure your data source and select files (**Browse...** picks folders and documents) |
| **[Processing](UI-TAB-PROCESSING.md)** | Start ingestion and monitor progress |
| **[Hybrid Search](UI-TAB-SEARCH.md)** | Hybrid Search and AI Query |
| **[AI Chat](UI-TAB-CHAT.md)** | Conversational AI over your documents |
| **[Graph](UI-TAB-GRAPH.md)** | The entities and relationships extracted from an ingest, search results or answer sources |

The header has one **sign-in pill** for every repository and cloud sign-in (a menu of servers),
and Search and AI Chat have a **Sources** picker (chips). Signed in, search and answers use only
documents you may read. See the
[Sign-In and Permission-Aware Search guide](../DATA-SOURCES/SIGN-IN-GUIDE.md).
